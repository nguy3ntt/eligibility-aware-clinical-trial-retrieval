# Interim data

Reproducible normalized outputs belong here locally. Every file must be derivable from raw data plus versioned code and configuration.

Examples include flattened trial records, field-profile tables, and parsed eligibility sections.

Milestone 1 writes profiles, a complete topic/qrel trace table with explicit trial-coverage gaps, original eligibility-format examples, and a pending ten-pair human-review worksheet. No canonical ingestion or criterion parsing is performed yet. Every output directory is new, links to its raw manifest checksum, and records code/configuration/output hashes. Use the offline profile command in `pipelines/README.md` to reproduce it. Generated files and synthetic narratives remain local and Git-ignored.
